MERGE INTO THE EXISTING REPOSITORY
1. Clone/pull your existing OnePageLove repository.
2. Copy the CONTENTS of this package into the repository root.
3. Keep your existing interactive HTML pages.
4. Run:
   python3 tools/verify_site.py
   git status
   git add .
   git commit -m "Add 1000-page OnePageLove chess library"
   git push
5. If GitHub Pages is not already enabled:
   GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root)
