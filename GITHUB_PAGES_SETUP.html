OnePageLove — GitHub Pages Setup

Copy the contents of this package into the root of the cloned OnePageLove repository. Existing standalone pages can remain there.

  1. Run python3 tools/verify_site.py.
  2. Run git add ..
  3. Commit the changes.
  4. Run git push.
  5. GitHub → repository Settings → Pages → Deploy from a branch → main → /(root).
python3 tools/verify_site.py
git status
git add .
git commit -m "Add 1000-page OnePageLove chess library"
git push

The site should then be available at https://knightway8.github.io/chess8/.
